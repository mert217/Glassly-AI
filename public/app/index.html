Hesaplar

Glassly API anahtarın

Glassly'yi kendi uygulamanda kullan. Herkes hesabıyla bir etkin anahtar oluşturabilir. Hesap başına günlük toplam 10, dakikada 2 istek; yanıt başına en fazla 512 token. Bu kota normal sohbetten ayrıdır. Başarısız denemeler de sayılır; anahtarı değiştirmek kotayı yenilemez. Günlük hak Türkiye saatiyle gece yarısı yenilenir.

Anahtarı şimdi kopyala. Tamamı bir daha gösterilmez; yalnızca güvendiğin kişiye ver.

API nasıl kullanılır?

OpenAI uyumlu. Base URL: https://glassly.biz/v1, model: glassly. Anahtarı tarayıcı kodunda veya herkese açık depoda paylaşma; sunucuda sakla.

curl https://glassly.biz/v1/chat/completions \
  -H "Authorization: Bearer ANAHTARIN" \
  -H "Content-Type: application/json" \
  -d '{"model":"glassly","messages":[{"role":"user","content":"Merhaba"}],"max_tokens":512}'
